# Job Filter & Tech Stack Research Extension

A Chrome extension designed to make job searching more efficient by automatically filtering irrelevant jobs and extracting useful technical insights from job descriptions.

## 🚀 Features

### 🗑️ Remove Unnecessary Jobs

Automatically filters job listings based on predefined criteria such as:

* Job roles and titles
* Company names
* Keywords
* Unwanted technologies or requirements

This helps reduce noise and allows you to focus on opportunities that match your preferences.

### 🔍 Job Description Analysis

Analyzes selected job descriptions from supported job platforms and extracts key information, including:

* Required technical skills
* Programming languages
* Frameworks and libraries
* Cloud platforms
* Databases
* DevOps tools
* AI/ML technologies
* Experience requirements

### 📊 Technical Stack Research

Provides a structured overview of the technical stack mentioned in a job description, helping candidates quickly understand:

* Core technologies required
* Preferred technologies
* Backend and frontend stack
* Infrastructure and cloud services
* Testing tools
* AI and data technologies

The extension can also highlight important technical requirements and assign relevance points based on their frequency and importance within the job description.

## 🌐 Supported Platforms

Currently designed to work with:

* LinkedIn Jobs
* Reed

Additional job platforms may be supported in future releases.

## 💡 Why This Extension?

Searching for jobs often involves manually opening hundreds of job listings and repeatedly reading similar descriptions. This extension helps automate repetitive tasks by:

1. Filtering unwanted job listings.
2. Identifying relevant opportunities faster.
3. Extracting technical requirements automatically.
4. Highlighting important skills and technologies.
5. Reducing the time spent manually reviewing job descriptions.

## 📦 Installation

1. Clone this repository:

```bash
git clone https://github.com/hcdev0127/jobfilter_extension.git
```

2. Open Google Chrome and navigate to:

```text
chrome://extensions/
```

3. Enable **Developer mode**.

4. Click **Load unpacked**.

5. Select the project directory.

6. Open LinkedIn Jobs or Reed and start filtering job listings.

## 🎯 Usage

### Filtering Jobs

Configure the roles, companies, or keywords you want to exclude. The extension automatically detects matching job listings and removes or hides them from the page.

### Analyzing a Job Description

1. Open a job listing.
2. Select or analyze the job description.
3. The extension extracts the technical stack.
4. Review the technologies and relevance points generated from the description.
